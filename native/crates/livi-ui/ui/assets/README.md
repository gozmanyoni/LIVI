# OpenNBT ID6 visual assets

## BMW roundel

`bmw-roundel.svg` is the period-correct 1997–2020 BMW roundel requested for this
BMW E90 interface. Source: [Wikimedia Commons, File:BMW.svg](https://commons.wikimedia.org/wiki/File:BMW.svg),
original file `https://upload.wikimedia.org/wikipedia/commons/4/44/BMW.svg`.
Downloaded 2026-10-31. Author: BMW. Commons identifies it as a public-domain
text/simple-geometry logo; the BMW trademark remains BMW's. This asset does not
imply affiliation or change the upstream LIVI notices.

## Rendered illustrations

The following transparent PNGs were created with the built-in imagegen tool on
2026-10-31 for this interface. They are decorative artwork, not vehicle telemetry
or a live map. Original outputs remain in the local generated-images directory;
project copies are self-contained here.

- `e90-m3.png`: silver BMW E90 M3 sedan, front-left three-quarter view.
- `id6-globe.png`: metallic navigation standby globe with an orange pointer.
- `id6-gear.png`: beveled brushed-aluminum settings cogwheel.

Generation prompts:

### Vehicle

Use case: product-mockup. Asset type: small vehicle status illustration for a BMW
NBT Evo ID6 infotainment screen. Render a precise BMW E90 M3 four-door sedan
(2008–2011) in metallic silver-grey, in an OEM automotive infotainment 3D-render
style, isolated on a genuinely transparent background. Landscape, whole car
fully visible, centered, front left three-quarter at slightly elevated angle,
nose toward lower left, car occupies 85% width, modest soft contact shadow only.
Correct E90 sedan four doors, M3 bulging bonnet, small kidney grilles,
characteristic headlamps, sport front bumper, silver multispoke wheels. No people,
environment, framing panel, captions or watermark. Neutral studio light, soft
silver highlights and black tyres, suitable for dark graphite. Keep recognisable
BMW front roundel and M3 shape. Bitmap illustration, not a UI screenshot.

### Navigation globe

A single navigation globe icon, a detailed three-dimensional Earth globe in
muted blue-grey oceans and realistic metallic silver continent outlines. Europe
and Africa centered, accurate recognizable continents. Slightly elevated front
view, silver latitude and longitude grid gently wrapping the globe, realistic
soft reflections on brushed metal. A curved brushed aluminum orbit ring supports
the lower hemisphere; a small orange-red triangular navigation pointer is in
front at the bottom. BMW NBT Evo ID6 era OEM infotainment graphical style,
sophisticated subtle 3D shading, not cartoon and not a flat vector. Isolated on
actual transparent background, square canvas. Whole globe fully visible with
comfortable margin. No labels, words, location pins or UI frame. Intended as a
260-pixel decorative navigation standby icon on a black display.

### Settings gear

A single solid eight-tooth cogwheel icon rendered in BMW NBT Evo ID6 era OEM
infotainment 3D graphics style. Brushed satin silver aluminum with beveled edges,
visible dark extruded sidewall to lower-right, large round center hole. Nearly
front-facing with subtle perspective so the metal bevel catches light; soft
upper-left illumination and restrained cool grey reflections. Sophisticated
realistic rendered material, not cartoon, not flat vector, no chrome mirror
glare. Actual transparent background, square canvas, fully visible gear centered
with margin. No words, numbers, badges, UI frame or other objects. Intended as a
200-pixel settings icon on a black display.

## Native vector artwork

`id6-backdrop.svg`, `id6-note.svg` and `id6-flag.svg` are original OpenNBT vector artwork under
GPL-3.0-or-later. UI fonts and small category icons continue to use the existing
bundled LIVI assets. No proprietary BMW font or map dataset is included.
